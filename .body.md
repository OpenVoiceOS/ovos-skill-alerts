## What this does

19 intent files carried CamelCase base names. OVOS-INTENT-2 §2 requires a
resource base name of lowercase ASCII letters, digits and underscores.

```
CreateAlarm            -> create_alarm
CreateAlarmAlt         -> create_alarm_alt
ChangeMediaProperties  -> change_media_properties
DAVSync                -> dav_sync
ListAlerts             -> list_alerts
TimerStatus            -> timer_status
... 19 in total
```

The four names that were already compliant do not move:
`create_reminder_recurring`, `delete_list_entries`, `missed_alerts` and
`query_list_entries`.

346 files are renamed: the same 19 intent names across 18 locales, and the
two `.blacklist` files whose base name must equal the intent they suppress
(OVOS-INTENT-2 §4.3), `ChangeMediaProperties.blacklist` and
`RescheduleAlert.blacklist`. The spec lint caught those two, which is what it
is for. The
`@intent_handler` decorators, the tests, the golden utterance files, the
example messages and the README follow. The CHANGELOG is a record of what
happened and is left alone.

No utterance changes. This is a file name and the intent name it registers,
not a template.

## Merge this with the bridge

A model trained before this rename emits the old label. `renames.py` in
`ovos-m2v-pipeline` maps an old label to the name the skill registers now, so
a published model keeps routing until a model trained on the new names ships.
The pairs for these 19 names are `OpenVoiceOS/ovos-m2v-pipeline#210`.

Merge the two together. This pull request alone breaks every published model
for this skill.
